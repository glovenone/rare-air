# Ten-language localization

The owner selected ten commonly used international languages on November 16. Supported languages are English, simplified Chinese, Spanish, French, Portuguese, German, Japanese, Russian, Modern Standard Arabic and Indonesian. English remains the source language and an accepted answer language.

Localize the complete game interface, its current 601 prompts and answer labels, topic descriptions, results, sharing, errors and website guides. Preserve canonical question IDs, scoring tiers, daily schedules and session ownership. Add localized answer aliases with Unicode-aware normalization. Preserve literal code keywords and single-letter answers. Keep translated question data server-side, reveal answer lists after completion, and package the translations for offline native practice.

Provide a persistent language selector, localized document language and Arabic RTL layout, localized public paths, canonical URLs, hreflang alternates and a sitemap. Explicit in-flight changes keep the same session and deadline. Translation content is generated during preparation and ships as local assets. Record machine-translation provenance and limitations, run coverage and alias-collision checks, and inspect representative scripts through the actual game UI before website publication. Existing native candidates require a new validated build before upload.

Implementation validation completed November 16: all 601 question records and 425 interface/guide messages cover the nine added languages. The generated site has 90 pages. Type checking, 34 unit tests, local D1 API integration, mobile asset packaging and WeChat compatibility builds passed. Browser checks covered Chinese, German, Japanese and Arabic, including 320px layout and language changes during a flight. Selected terminology corrections and aliases are recorded in the translation overrides; the whole corpus has not had native-speaker review. Native assets are prepared, but this website update does not publish new App Store or Android store binaries. The separate WeChat UI remains English.
