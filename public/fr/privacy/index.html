Politique de confidentialité.

Entrée en vigueur le 16 novembre 2026. RARE Air est exploité par le mainteneur du projet, glovenone, et son code source est disponible sur GitHub. Cette politique couvre le jeu web, les applications mobiles RARE Air packagées et l'édition jeu WeChat.

Jouer à RARE Air ↗

Données utilisées pour le jeu en ligne.

Le jeu utilise un identifiant de joueur généré aléatoirement pour conserver une tentative quotidienne et sa session de jeu. Les sessions en ligne stockent la date, le mode, le nom d'affichage généré, l'instantané de la question, les réponses choisies, les scores et les informations de temporisation. Les classements quotidiens affichent les noms générés et les totaux.

Un cookie de navigateur nommé rare_player stocke votre identifiant de joueur anonyme pendant un an maximum. Dans l'application mobile, le magasin de cookies de réseau natif maintient la session correspondante. Le jeu WeChat conserve ce cookie anonyme dans le stockage local de l'appareil. Le jeu invité ne nécessite aucun compte. Le jeu WeChat séparé ne demande pas de profil WeChat ni d'OpenID.

Données stockées sur votre appareil.

Le stockage local conserve les identifiants de session enregistrés, l'historique des vols quotidiens terminés et l'historique de la pratique hors ligne. Les questions de pratique hors ligne et le scoring fonctionnent sur votre appareil. Les navigateurs web et les applications mobiles pris en charge ouvrent le panneau de partage de votre système d'exploitation. Le partage web offre également un presse-papiers de secours. Le partage WeChat utilise les contrôles de partage de WeChat. Vous choisissez si et où partager un score.

Le son est facultatif. Les haptiques utilisent le matériel de vibration du téléphone là où il est pris en charge. Ces fonctionnalités ne nécessitent pas l'accès au microphone, à la caméra, aux contacts ou à la localisation.

Salons de relais privés.

Les salles de relais stockent les noms des pilotes, les réponses, les scores, les choix de compagnons et les jetons de siège privé. Les salles expirent après 24 heures. Les enregistrements expirés sont supprimés lorsqu'une nouvelle salle est créée. Cet onglet conserve votre jeton de siège dans le stockage de session. Les participants à la salle peuvent voir votre nom de pilote, votre score, votre compagnon et vos réponses acceptées. Les salles d'attente publiques exposent le pseudo de l'hôte, la capacité et le code de la salle. Choisissez un pseudo sans informations personnelles.

Analytique de site web facultative.

Lorsque vous autorisez l'analytique, le site web charge Google Analytics 4 pour mesurer les visites, les sessions, les pages vues, les sources de trafic, les informations sur les appareils et les pays, ainsi que les clics sur les liens de téléchargement Android ou Apple. Google traite les informations techniques de la requête pour fournir ce service. Les cookies _ga et _ga_ aident à distinguer les visites et peuvent persister pendant deux ans.

La balise analytique se charge après que vous l'ayez autorisée. Utilisez les paramètres d'analytique pour refuser ou modifier votre choix, qui est stocké sous forme de rare_analytics_consent sur ce navigateur. Le refus arrête la collecte d'analytiques et supprime les cookies Google Analytics de ce site web. Les outils de confidentialité du navigateur ou les scripts bloqués peuvent également limiter la collecte.

Les réponses trivia saisies, les identifiants de session de jeu et les identifiants de joueur sont exclus des événements d'analytique. Les adresses de page et les référents sont envoyés avec les chaînes de requête et les fragments supprimés. Le stockage publicitaire, la personnalisation publicitaire et les signaux Google sont désactivés. Cette intégration d'analytique de site web est exclue des jeux mobiles et WeChat emballés.

Les informations de confidentialité de Google sont disponibles à https://policies.google.com/privacy et https://policies.google.com/technologies/partner-sites. Contactez contact@shanxing.top pour les questions de confidentialité.

Préparation de la publicité sur le site web.

Le site web publie une balise meta de vérification de propriété Google AdSense et un fichier de autorisation ads.txt pour l'examen du site. La diffusion des publicités est actuellement désactivée. Ces enregistrements de vérification statiques identifient le compte de l'éditeur. Toute activation future de la publicité sera reflétée dans cette politique et les contrôles de confidentialité du site web.

Journaux d'hébergement et de service.

Cloudflare Workers et D1 hébergent le jeu en ligne et la base de données de gameplay. Cloudflare traite les requêtes réseau et peut traiter les adresses IP, les détails des requêtes et les journaux de service pour exploiter et protéger le service. Le jeu active l'observabilité des Workers pour diagnostiquer les pannes de service.

Les réponses au gameplay et les enregistrements anonymes sont utilisés pour exploiter le scoring, la récupération de session et les classements.

Conservation et vos choix.

Les données locales du navigateur restent tant que vous ne les effacez pas. Vous pouvez supprimer l'historique local en effaçant les données du site ou en supprimant l'application mobile. Les enregistrements de jeu en ligne restent dans la base de données du service tant que le service fonctionne, à moins qu'ils ne soient supprimés par l'opérateur.

Pour une demande de données, contactez le mainteneur via la page de support. Incluez l'ID de partie sauvegardée si vous pouvez le fournir de manière privée. Ne publiez que des détails non sensibles dans les problèmes publics GitHub.

Mises à jour et contact.

Cette politique peut évoluer avec les fonctionnalités du jeu. La date d'entrée en vigueur identifie la révision actuelle. Utilisez la page de support pour les questions de confidentialité ou les demandes de données.

Passeports de vol facultatifs.

Un passeport gratuit stocke un nom de pilote public, une identité de jeu privée, un code de récupération haché, des sessions de connexion hachées, des clés publiques de passkey, des préférences, des amis et des historiques de notation dans Cloudflare D1. Nous ne collectons pas d'adresse e-mail, de mot de passe ou de données biométriques. Votre appareil gère la vérification par passkey. Gardez votre code de récupération privé ; toute personne le possédant peut ouvrir votre passeport.

Les cookies de connexion expirent après 30 jours. Les défis de passkey expirent après cinq minutes et sont à usage unique. Les invitations d'amis expirent après sept jours. Les vols précédents d'un invité ne sont liés qu'après que vous ayez choisi d'importer l'historique de cet appareil. L'entraînement hors ligne reste sur son appareil.

Les amis ne peuvent comparer les réponses quotidiennes terminées qu'après avoir effectué eux-mêmes ce vol quotidien. Les tableaux notés stockent les positions d'arrivée et les changements de notation. Les blocages empêchent de nouvelles relations d'amitié et la mise en correspondance avec des comptes bloqués. Les rapports stockent le rapporteur, le pilote, la salle, l'explication et l'heure pour la modération ; contactez le support pour les préoccupations urgentes.

Utilisez Récupération et suppression dans votre passeport pour remplacer un code de récupération ou supprimer définitivement votre passeport et son historique de vol en ligne associé. La suppression nécessite le code de récupération actuel. Les instantanés de salle publique expirent séparément après 24 heures. Les limites de taux de sécurité stockent des clés de requête hachées à courte durée de vie plutôt que des adresses IP brutes.
