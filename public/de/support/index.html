Ein wenig Hilfe zum Abheben.

Der RARE Air-Support wird vom Open-Source-Projektbetreuer abgewickelt. Senden Sie eine E-Mail an contact@shanxing.top für Support- oder Datenschutzanfragen. Für einen Spielbug, eine Antwortkorrektur oder eine Bereitstellungsfrage können Sie auch ein Issue im GitHub-Repository des Projekts öffnen.

RARE Air spielen ↗

Ein Problem melden.

Fügen Sie das Puzzledatum, die Eingabeaufforderung, Ihr Gerät und Ihre Browser- oder App-Version sowie das Geschehene hinzu. Ein Screenshot kann helfen, ein Layoutproblem zu zeigen. Vermeiden Sie die Weitergabe privater Details in öffentlichen Issues.

Verwenden Sie https://github.com/glovenone/rare-air/issues, um den Betreuer zu erreichen. Wenn ein Bericht private Informationen erfordert, fordern Sie einen privaten Kontaktkanal an, bevor Sie diese Informationen einfügen.

Meine Antwort wurde abgelehnt.

Jede Eingabe hat eine kuratierte Liste gültiger Antworten und akzeptierte Alternativen. Überprüfen Sie den genauen Umfang der Eingabe und vergleichen Sie Ihre Schreibweise mit den in der abgeschlossenen Flugberichts angezeigten gültigen Antworten. Melden Sie eine fehlende gültige Antwort mit einer Quelle, die sie unterstützt.

Der Timer lief weiter.

Eine aktive Online-Frage verwendet die Serverzeit. Das Wechseln der Registerkarten, Öffnen der Hilfe oder Schließen der App lässt diese Uhr weiterlaufen. Zwischen den Fragen können Sie auf dem Belohnungsbildschirm verbleiben, bis Sie „Höher klettern“ auswählen.

Mein täglicher Flug oder meine Historie fehlt.

Online-Versuche verwenden ein anonymes Cookie und lokale Sitzungs-IDs. Das Löschen von Cookies, das Wechseln des Browsers oder das Entfernen von App-Daten kann eine andere lokale Identität erzeugen. Die gerätespezifische Historie bleibt auf dem Gerät erhalten, auf dem Sie gespielt haben.

Offline-Übungsflüge werden lokal in der mobilen App gespeichert. Sie sind vom täglichen Online-Ranking getrennt.

Datenschutzanfragen.

Siehe die Datenschutzrichtlinie für die vom Spiel verwendeten Daten. Kontaktieren Sie den Betreiber, bevor Sie Kennungen oder persönliche Informationen in einem öffentlichen Bericht teilen.
